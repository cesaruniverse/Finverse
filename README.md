# ⚡ FinVerse — Cyber-Finance System

> Modern, futuristic, and cloud-synced personal finance desktop application built with Python and Supabase.

![FinVerse Banner](Finverse%20logo.jpg)

**FinVerse** es una aplicación de escritorio orientada a la gestión de finanzas personales con una estética **Cyberpunk / Neón**. Ofrece sincronización en tiempo real en la nube, control de presupuesto, gestión de perfil de usuario y soporte dinámico para temas claro y oscuro.

---

## ✨ Características Principales

* **☁️ Sincronización en la Nube:** Conexión directa a **Supabase** para almacenamiento seguro de transacciones en tiempo real.
* **🔒 Autenticación Segura:** Registro e inicio de sesión integrados mediante Supabase Auth con protección del lado del servidor.
* **📊 HUD Financiero:** Tarjetas de balance en tiempo real con cálculo automático de ingresos, gastos y saldo neto.
* **🎨 Estética Cyberpunk Adaptativa:** Interfaz construida con `customtkinter` en tonos cian y magenta neón, con cambio de tema Claro/Oscuro en tiempo real.
* **⚙️ Gestión de Perfil:** Personalización de alias/apodo, cambio de interfaz y opción de eliminación definitiva de cuenta.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Python 3.14+
* **Interfaz Gráfica:** `customtkinter` & `tkinter.ttk`
* **Backend & Base de Datos:** Supabase (Auth & PostgreSQL)
* **Procesamiento de Imágenes:** Pillow (`PIL`)
* **Empaquetado:** PyInstaller & Inno Setup
